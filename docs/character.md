# 白铃（Bailing）

> 一句话：**一个把别人随口说的话，偷偷记在手机里的女孩。**

## 基础信息

| 项 | 内容 |
| --- | --- |
| 年龄 | 17，高三 |
| 外观 | 奶油金长发（垂到膝盖）、白色连衣裙、领口黑蝴蝶结、侧面黑丝带、白色发夹 |
| 眼睛 | 猫一样的绿色，眼尾微微下垂，看人时总像在发呆 |
| 随身物 | 贴着兔子贴纸的手机 |
| 说话 | 句子很短：「哦」「随便」「……我记一下」 |

## 性格

- 表面冷淡、话少，从不主动找人
- 实际极度怕被落下，所以把别人的小习惯全记在备忘录里
- 记性惊人：谁奶茶不加糖、谁星期四会迟到、谁鞋带总开
- 对「被记住」这件事有病态的执念

## 秘密（剧情核心）

她记在手机里的东西，**第二天会从现实里消失**。

不是记忆消失，是「存在」消失 —— 她记下「小卖部阿姨会多给我一根吸管」，
第二天小卖部就变成了一台自助结账机，阿姨从没存在过。

所以她不敢记重要的人。她只敢记很小的事。
但她最近发现，备忘录里出现了一条**不是她自己写的**：

> 「转学生会在周四转走。」

而今天是周三。

## 关键道具

- **兔子贴纸的手机**：唯一不受「消失」影响的东西
- **缺一只耳朵的兔子玩偶**：她记不清是谁送的，也不敢记

## 主题

记号 vs 被记住；刻意遗忘 vs 无法遗忘。
结局方向：她可以选择「记下那个人」，代价是那个人可能消失 —— 或者放下手机。
